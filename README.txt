NUSATECH - COMPANY PROFILE SEDERHANA

File:
- index.html       : Beranda
- about.html       : Tentang Kami
- services.html    : Layanan
- portfolio.html   : Portofolio
- contact.html     : Kontak
- style.css        : Pengaturan tampilan seluruh halaman

Teknologi:
HTML dan CSS native saja. Tidak menggunakan JavaScript, Bootstrap, atau framework.

Cara menjalankan:
1. Extract ZIP.
2. Buka folder company_profile_layout_bagus.
3. Klik dua kali index.html.
4. Gunakan menu navigasi untuk berpindah halaman.

Catatan:
Nama perusahaan, layanan, alamat, email, dan proyek adalah contoh yang bisa disesuaikan.
Portofolio merupakan ilustrasi contoh, bukan klaim proyek nyata.
